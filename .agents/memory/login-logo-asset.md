---
name: Login logo asset
description: Explains why the cropped Stable Eye wordmark must be used on the login page.
---

Use the cropped Stable Eye wordmark when displaying the full logo on compact layouts.

**Why:** The original square PNG contains substantial transparent padding, so increasing its CSS dimensions barely changes the visible logo and behaves inconsistently across screen sizes.

**How to apply:** Use a tightly cropped asset with normal responsive width and automatic height instead of compensating with background sizing or oversized image dimensions.
