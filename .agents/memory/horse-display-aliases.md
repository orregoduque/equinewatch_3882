The user wants to see “Sancho” instead of “Thunder” in this app, as a visual
alias only. Keep the stored horse name and all database, Wasabi, camera,
receiver and publisher associations unchanged.

**Why:** The user cares about the name shown to customers and explicitly wants
to avoid changes or problems in the database, Wasabi and other apps.

**How to apply:** Resolve display aliases by the existing horse identity, not
by global text replacement. Do not rename technical identifiers containing
Thunder or infer that another horse with the same name should receive the alias.
